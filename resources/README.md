# Resources — Free Stack

Rule: **buy nothing in Year 1.** Everything below is free.

## Year 1 — classical & chaotic dynamics
- **Mark Newman — *Computational Physics*** — the spine text. Project-driven, Python-based, physics-through-code. Practically written for your profile.
- **3Blue1Brown — Essence of Linear Algebra + Essence of Calculus** (YouTube) — visual intuition for reactivating dormant math.
- **Khan Academy** — patch specific gaps, one topic at a time. Never front-to-back.
- **NumPy / Matplotlib / SciPy docs** — reference while building, not reading cover to cover.

## Year 2 — quantum mechanics simulation
- **Susskind — *The Theoretical Minimum: Quantum Mechanics*** — written for engineers pivoting in.
- Newman's QM chapters for the code side.

## Year 3+ — contribution / quantum-computing bridge (optional)
- **Nielsen & Chuang — *Quantum Computation and Quantum Information*** ("Mike & Ike").
- Cirq / QuTiP source + their "good first issues".
